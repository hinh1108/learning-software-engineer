# Training

Thư mục này chứa các khóa tự học chuyên sâu cho từng công cụ trong [toolkit](../toolkit/). Mỗi khóa là một thư mục con gồm bài học đánh số, cheatsheet và bài tập thực hành. Bài học viết theo phiên bản công cụ đã dùng thực tế, ghi rõ ở đầu mỗi khóa.

| Khóa | Công cụ | Nhóm kỹ năng liên quan | Trạng thái |
| --- | --- | --- | --- |
| [gitnexus/](gitnexus/) | GitNexus, code knowledge graph cho AI agent | Xuyên suốt, 2. Lập trình, 4. System design | Bản đầu |

## Quy ước

- Mỗi khóa có `README.md` nêu mục tiêu, yêu cầu đầu vào và thứ tự bài học.
- Bài học đặt tên `NN-<chu-de>.md`, đọc theo thứ tự số.
- Lệnh trong bài đã chạy thử trên phiên bản ghi ở đầu khóa; phần chưa kiểm được đánh dấu "chưa kiểm".
- Bài tập đặt trong file `bai-tap.md` của từng khóa, kết quả làm bài lưu trong thư mục `notes/` của khóa đó.
